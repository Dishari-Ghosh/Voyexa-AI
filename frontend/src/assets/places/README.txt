Drop place photos here.

Name each file with the place_id first, then (optionally) a readable name:

    635_pangong-lake.jpg
    640_shanti-stupa.jpg
    1.jpg                     <- also fine

Supported: .jpg .jpeg .png .webp .avif
Run  python scripts/make_image_checklist.py  from the project root to get
data/place_image_checklist.csv - every place with its exact suggested filename
and whether it still needs an image.

Tip: resize photos to about 1000px wide (under ~200 KB each) so 1,100+ images
don't make the app heavy.
