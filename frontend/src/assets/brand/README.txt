LOGO GOES HERE

  Save your logo as:   frontend/src/assets/brand/logo.png     (or logo.jpg)

Recommended: square, 512 x 512 px, PNG with a transparent background.
(A wide logo also works - it is fitted inside a 20 x 20 mm box on the PDF and
an 8 x 8 px-unit box in the header without being stretched - but a square mark
looks best in both places.)

Once the file exists it appears automatically:
  - in the website header, left of "Voyexa AI"
  - in the website footer
  - top-left corner of every itinerary PDF

Also save a small copy (64 x 64 px or larger, square PNG) as
  frontend/public/favicon.png
for the browser-tab icon.
